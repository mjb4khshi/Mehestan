# مهستان | Mehestan

کلاینت مدرن، سریع و هوشمند سامانه یادگیری الکترونیکی مودل (Moodle LMS) ویژه دانشجویان دانشگاه‌های کشور، با دیزاین‌سیستم سرو و یکپارچه با اکوسیستم سروستان.

---

## ویژگی‌های کلیدی

- **اتصال مستقیم به وب‌سرویس رسمی مودل:** ارتباط امن مبتنی بر توکن با پروتکل استاندارد Moodle Mobile Web Services.
- **دیزاین‌سیستم سرو (Sarv UI):** مجهز به تایپوگرافی اصیل آراد (Dots 2)، کارت‌های شیشه‌ای، تم‌های تاریک و روشن اصیل ایرانی.
- **پل ارتباطی با سروستان (Cross-App Bridge):** انتقال مستقیم و خودکار تکالیف، آزمون‌ها و ددلاین‌های مودل به تقویم، کارهای مطالعه و ویجت‌های صفحه اصلی اپلیکیشن سروستان.
- **پشتیبانی از دانشگاه‌های مطرح:** سامانه‌های مودل دانشگاه‌های صنعتی خواجه نصیرالدین طوسی، شهید بهشتی، تهران، صنعتی امیرکبیر و امکان اتصال به هر آدرس دلخواه LMS.
- **مشاهده و دانلود اسلایدها و منابع:** دسترسی سریع به سرفصل‌ها، فایل‌های درسی و اسلایدهای جلسات هفتگی.

---

## پشته فنی (Tech Stack)

- **هسته وب:** React 19 + Vite 6
- **استایل و طراحی:** Tailwind CSS v4 + Sarv UI
- **آیکون‌ها:** Lucide React
- **انیمیشن:** Framer Motion
- **پلتفرم همراه:** Capacitor 8

---

## راه‌اندازی و توسعه محلی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت نسخه نهایی
npm run build
```

## معماری ارتباطی با مودل

تمامی درخواست‌ها به اندپوینت‌های استاندارد مودل ارسال می‌شوند:
- احراز هویت و دریافت توکن: `/login/token.php?service=moodle_mobile_app`
- فراخوانی توابع وب‌سرویس: `/webservice/rest/server.php?moodlewsrestformat=json`
